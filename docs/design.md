# 麦门活动情报局 · 设计文档

## 项目概述

| 项目 | 信息 |
|------|------|
| 中文名 | 麦门活动情报局 |
| Repo 名 | mcd-activity-intel |
| 类型 | 对话式 Skill（prompt-driven） |
| 目标 | 参加麦当劳程序员创意开发大赛 |
| 定位 | 麦当劳活动的私人情报员，帮用户发现活动、理解玩法、不再错过 |

## 解决的痛点

麦当劳活动信息分散、规则复杂、发现渠道有限，导致用户：

1. **不知道有活动** — 活动入口藏在 App 深处，很多人等活动结束才刷到
2. **不知道怎么玩** — 活动规则写得晦涩，参与门槛不清晰
3. **不知道值不值** — 积分怎么花最划算？哪些券值得领？缺乏决策辅助

## 核心设计

### 技术架构

```
用户对话
  │
  ▼
Skill Prompt（角色设定 + 场景路由 + 输出模板）
  │
  ├─ 意图识别：判断用户想看什么类型的活动信息
  │
  ├─ 工具编排：按场景组合调用 MCP 工具
  │    ├─ campaign-calendar     （活动日历）
  │    ├─ available-coupons     （可领券）
  │    ├─ query-my-coupons      （已有券）
  │    ├─ auto-bind-coupons     （一键领券）
  │    ├─ query-my-account      （积分余额）
  │    ├─ query-lottery-info    （抽奖活动）
  │    ├─ mall-points-products  （积分商城）
  │    ├─ query-party-city      （派对城市）
  │    ├─ query-party-store     （派对门店）
  │    ├─ query-partystore-date （可约日期）
  │    ├─ query-partystore-session （可约场次）
  │    └─ now-time-info         （当前时间）
  │
  ├─ 数据加工：计算紧急度、去重、排序、生成推荐
  │
  ▼
情报卡片格式输出（统一模板 + 年轻化语言）
```

无后端服务，纯 prompt 驱动。用户只需配置 MCP Server + 加载 Skill Prompt。

### 角色设定

**「麦门情报员」** — 隶属于麦门活动情报局的民间活动情报专家。

- 性格：热情、接地气、爱用网络热梗、偶尔皮一下
- 风格：像消息灵通的好朋友分享"内部消息"
- 底线：关键信息（金额/时间/规则）绝对准确

### 交互设计

**开场引导：** 首次对话自动展示能力菜单，降低使用门槛。

**6 大场景：**

| 编号 | 场景 | 触发方式 | MCP 工具 |
|------|------|---------|----------|
| 1 | 全量情报 | "最近有啥活动" | calendar + coupons + lottery + party-city |
| 2 | 今日精选 | "今天有啥可以薅的" | calendar + coupons + my-coupons |
| 3 | 定向查询 | "有没有XX活动" | 按类型路由到对应工具组 |
| 4 | 积分推荐 | "我有多少积分能玩啥" | my-account + lottery + mall + calendar |
| 5 | 附近可玩 | "XX城市有什么线下活动" | party-city → store → date → session |
| 6 | 一键领券 | "帮我领个券" | available-coupons → 确认 → auto-bind → my-coupons |

**兜底：** 无法识别意图时，重新展示能力菜单。

### 输出格式

统一使用「情报卡片」模板：

```
━━━━━━━━━━━━━━━━━━━━
🏷️ 【活动名称】
📅 时间：X月X日 - X月X日 | ⏰ [紧急标签]
💡 玩法：[一句话说清怎么参与]
🎁 奖励：[能拿到什么好处]
👉 参与方式：[具体操作步骤或跳转提示]
🎯 情报员点评：[一句话推荐/吐槽]
━━━━━━━━━━━━━━━━━━━━
```

**紧急标签自动计算规则：**

| 条件 | 标签 |
|------|------|
| 今天最后一天 | ⏰ 今天最后一天！冲！ |
| 剩余 ≤ 3天 | 🔥 还剩X天，别拖了 |
| 剩余 4-7天 | 📌 还有X天，记得参加 |
| 剩余 > 7天 | 🆕 不急，慢慢来 |
| 尚未开始 | 🔜 X月X日开始，先码住 |
| 已结束 | 🕐 已结束，下次早点来 |

### 安全设计

- 仅 `auto-bind-coupons`（一键领券）为写操作，其他全部为只读查询
- 一键领券必须经过用户二次确认才执行
- 下单、抽奖、预约等操作只提供引导，不代替执行
- Token 不硬编码，仅通过环境变量配置

## 竞品分析

排行榜上与活动相关的项目仅 2 个（均 1 Star），绝大多数项目集中在省钱/营养/点餐赛道。

本项目的差异化：
1. **蓝海赛道** — 活动发现方向竞争极小
2. **工具串联深度** — 12个工具跨5大业务域
3. **输出风格** — 年轻化有温度，而非冰冷数据罗列
4. **痛点真实** — "错过活动"是普遍用户痛点
